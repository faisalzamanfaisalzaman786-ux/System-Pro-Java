# Android Master Template

This repository is a template for Android apps built with Gradle 8.5 and AGP 8.3.2.

**Placeholders used:**
- `com.systempro.myapp` - Java package name
- `com/systempro/myapp` - Package path with slashes
- `Testing ` - Application display name

When you generate a new repository from this template, these placeholders will be replaced automatically by the System Pro UI.
